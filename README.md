# Systems & Research

## Signoff Reconciliation Engine

A human-in-the-loop document intelligence and reconciliation system designed to compare operational signoff evidence against structured planning records.

The architecture separates AI-based evidence extraction from deterministic business logic.

```text
SIGNOFF DOCUMENTS
        │
        ▼
EVIDENCE EXTRACTION
        │
        ▼
STRUCTURED EVIDENCE
        │
        ▼
DETERMINISTIC RULES
        │
        ▼
PLANNING RECONCILIATION
        │
        ▼
GREEN / AMBER / RED
        │
        ▼
HUMAN REVIEW
        │
        ▼
CONTROLLED STAGING
```

Engineering capabilities include:

- Visual document evidence extraction
- Deterministic business rules
- Evidence provenance
- Planning-record matching
- Multi-record reconciliation
- GREEN / AMBER / RED decisions
- Human review safeguards
- Read-only source controls
- Controlled downstream staging
- Automated testing
- Continuous Integration

**Current engineering status**

- 76 automated tests
- GitHub Actions CI
- Multi-record signoff reconciliation
- Field-level evidence provenance
- Human review architecture

The project demonstrates a core MASH LABS principle:

> **Use AI for interpretation. Use deterministic engineering for control.**

# Engineering Principles

MASH LABS systems are developed around several principles.

### Business First

Start with the problem, process and desired outcome — not the algorithm.

### Data Before Models

Understand, validate and engineer the data before optimising machine-learning models.

### Reproducibility

Experiments, datasets, models and engineering decisions should be traceable and repeatable.

### Deterministic Controls

Where business rules require certainty, deterministic logic should remain authoritative.

### Human Oversight

AI should support human decision-making where uncertainty or operational risk requires review.

### Production Thinking

A successful experiment is not automatically a successful system.

Production requires testing, monitoring, versioning, deployment controls and maintainability.
