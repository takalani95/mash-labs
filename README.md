\# MASH LABS



\*\*Data · Intelligence · Engineering\*\*



MASH LABS is an independent technology lab focused on building practical systems across data science, machine learning, MLOps, applied AI, analytics and intelligent automation.



> We build systems, not demos.



\---



\## About



MASH LABS explores how data, machine learning and software engineering can be combined to solve real-world operational and business problems.



The focus is not only on developing models or experiments, but on engineering reproducible, testable and maintainable systems around them.



\---



\## Selected Work



\### Signoff Reconciliation Engine



A human-in-the-loop document intelligence system designed to reconcile operational signoff evidence against structured planning records.



The system combines:



\- Visual document evidence extraction

\- Deterministic business rules

\- Evidence provenance

\- Planning record matching

\- GREEN / AMBER / RED reconciliation decisions

\- Controlled downstream staging

\- Human review safeguards

\- Automated testing

\- Continuous Integration



\*\*Current engineering status:\*\*



\- 76 automated tests

\- GitHub Actions CI

\- Multi-record signoff reconciliation

\- Field-level evidence provenance

\- Read-only source controls

\- Human review architecture
